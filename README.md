One short line about office life, entered in the make.fun bounty
[The Funniest Office Joke, Judged Head to Head](https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c).

The program writes a single joke to `/output/entry.txt`:

> The printer jammed on deadline day and filed a grievance.

Run it with `node main.ts`. It needs nothing but Node.
